# Assignment 06 - Patterns

## Questions Solved

1. **Binary Triangle Pattern** - Alternating 0s and 1s triangle
   Input: `4`
   Output:

   ```
   1
   01
   101
   0101
   ```

2. **Rectangle Star Pattern** - Right-aligned rectangle
   Input: `4`
   Output:

   ```
      ****
     ****
    ****
   ****
   ```

3. **Hollow Diamond Pattern** - Diamond outline only
   Input: `4`
   Output:

   ```
      *
     * *
    *   *
   *     *
    *   *
     * *
      *
   ```

4. **Palindrome Number Pattern** - Palindromic number pyramid
   Input: `4`
   Output:
   ```
      1
     121
    12321
   1234321
   ```
